# 0.1.0a2 — installation and diagnostic improvements

- Run the installed CLI as `python -m agentinputlab`; use `--version` to verify
  which environment/version is active.
- Reject empty model IDs, invalid/non-finite timeouts, malformed API roots and
  accidentally supplied full `/chat/completions` URLs before model dispatch.
- Surface sanitized HTTP status codes and setup hints through
  `OpenAICompatibleTransportError`, still compatible with `RuntimeError`.
  Provider bodies, credentials and request URLs are not retained.
- Add a first-run guide and an explicit, single-call real HTTP backend example.
- Document public source/documentation retrieval from PyPI without requiring
  access to the private research repository.

The backend still performs one transport attempt with no implicit retries.
Model parameters, scoring, result accounting and benchmark scope are unchanged.
No additional model experiments were needed for these consumer-interface fixes.
The Git source was reconciled against the exact published 0.1.0a1 source
distribution before preparing this patch release.

Upgrade explicitly while the project is in alpha:

```sh
python -m pip install --upgrade agentinputlab==0.1.0a2
python -m agentinputlab --version
python -m agentinputlab smoke --json
```
