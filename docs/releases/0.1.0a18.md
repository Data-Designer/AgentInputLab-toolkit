# 0.1.0a18: RRR query-format compatibility

The common-support RRR profile now accepts a complete, single-line query wrapped
in Markdown bold. When the GPT-OSS final-channel stop adapter has truncated that
wrapper, RRR can recover the single query from the retained final response.
Incomplete wrappers, multiple queries and reasoning-only output remain rejected.
The trace records normalization and the retained final-content hash.

Saved-response regression preserved 120 scored runs and seven real failures.
One previously blocked case was completed by reusing its original rewrite and
issuing only the two unstarted downstream requests. Native scoring completed
within the original budget; prompts, model, seeds and scorer were unchanged.

The existing ATD format fix and ToolSandbox tool-call-ID syntax repair remain
included. Full profile/benchmark/backbone execution coverage is still being
audited; these regression results are not a claim that the whole matrix passed.

Install with `python -m pip install --upgrade agentinputlab==0.1.0a18`.
