# 0.1.0a9: executable verification instructions

This documentation maintenance release corrects the testing instructions shipped
with 0.1.0a8. Algorithm implementations, runtime configuration, budgets and
benchmark scorers are unchanged.

## Check an installed package

The PyPI source archive includes the consumer audit. After installing the package,
unpack that archive and run:

```sh
python tools/check_consumer_contracts.py
```

This checks installed Python and command-line interfaces, discovery metadata,
authenticated HTTP transport and invalid requests, without downloading datasets
or calling models.

## Run the full development suite

Use a source checkout containing `tests/`:

```sh
python -m pip install '.[dev]'
python -m pytest
```

The PyPI source archive does not contain `tests/`. Native worker tests declare
the pinned checkouts and optional dependencies they require. See
`agentinputlab docs acceptance-coverage` for real-model acceptance boundaries.
