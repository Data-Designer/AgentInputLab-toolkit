# 0.1.0a16: user-facing setup and provenance repair

- Added English / Chinese README navigation and complete paired tutorials for
  installation, configuration, real API calls, native scoring and local Studio.
- Added an executable RRR example and documentation regression tests.
- Inline BM25 documents now receive content-derived provenance when no explicit
  revision is supplied. This fixes RRR failing after a successful rewrite because
  the tutorial corpus lacked a revision. Existing explicit revisions are preserved.
- The unified Studio workflow now visibly offers its supported one-worker setting.
  The separate campaign interface retains its concurrency support.
- Corrected stale development-only and installation-version instructions.

Install with `python -m pip install --upgrade agentinputlab==0.1.0a16`.
Offline guides: `agentinputlab docs tutorial` and
`agentinputlab docs tutorial.zh-CN`.

This maintenance release does not change scientific results, benchmark scorers,
method budgets, trained artifacts or algorithm parsing rules. Its installed-user
acceptance is documented separately from synthetic regression tests.
