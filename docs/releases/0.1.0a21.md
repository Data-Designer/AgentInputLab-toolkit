# AgentInputLab 0.1.0a21

Active Task Disambiguation now supports an opt-in two-stage H2/Q2 layout.
It first samples two hypotheses and then requests two questions and their
answer categories in one response. It selects a question using the same
uniform empirical information gain as the default layout.

To enable it, set `controls.request_layout` to `joint_h2q2`. Configure the
512- and 1,024-token stage caps and keep both requests within the shared
run budget. See the [configuration guide](../configuration.md#active-task-disambiguation-joint-h2q2)
for a complete example. The default separate-call layout is unchanged.
