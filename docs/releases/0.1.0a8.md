# 0.1.0a8: file-based execution and benchmark evaluation

This release connects editable run files to existing method runtimes, frozen
artifacts, native arena execution, and benchmark scoring. Install with
`python -m pip install agentinputlab==0.1.0a8`, then use
`agentinputlab docs configuration` or `agentinputlab docs fit-configuration`.

From the unpacked PyPI source distribution, run
`python tools/check_consumer_contracts.py` against your installed package.
The full regression suite runs from a source checkout after
`python -m pip install '.[dev]'`, followed by `python -m pytest`;
the PyPI source distribution does not include `tests/`.
Source-specific tests list their pinned checkouts and optional dependencies.
The installed `docs` command includes the setup and execution guides.

## Configuration and reuse

Model connection, seed, cumulative budget, method parameters, and retriever are
explicit fields in the run file. Relative artifact paths resolve beside the
configuration file. Each selected benchmark case receives its own run budget;
method and downstream calls share that case's budget. Existing frozen artifacts
and saved responses can be reused with their recorded identity and cost.

`config run` returns a method result; `config evaluate` returns native benchmark
scores. Native interactive arenas use `config evaluate-arena`. Choose the command
that matches the task and provide the native runtime assets listed in its guide.

## Execution scope

The catalog contains native, adapted, cached, component, and fitting profiles.
Their requirements differ. Author-released caches require matching queries;
frozen skills require their fitted artifact; checkpoint-native R2AG requires its
pinned reader architecture and candidate count. Modern backbones unsupported by
that pinned runtime report `READER_CONFIG_INCOMPATIBLE` before neural execution.

Evaluation preserves empty outputs, protocol errors, budget exhaustion, and
scored zeroes in per-case records. It does not automatically retry a consumed
attempt. A passing interface test establishes that interface's behavior; native
source and model acceptance records have their own explicitly tested scope.

Previously deferred training, sandbox execution, and benchmark/method items
remain deferred. This release changes the toolkit; paper results are unchanged.
