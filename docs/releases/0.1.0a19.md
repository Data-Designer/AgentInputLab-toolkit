# 0.1.0a19: Q-RAG file configuration and native scoring

- Native Q-RAG file configuration accepts the explicit
  `runtime.single_candidate_axis_compat` setting for a live frozen selector.
  It remains off by default and cannot be combined with a saved policy replay.
- Q-RAG's instruction-preserving QA reader sends an empty answer string to the
  native scorer as returned. Missing and non-string answers are still errors.
- LongBench scores the decoded `answer` field verbatim when
  `composite_output_format` is `structured_qa_json`, preserving indentation
  and other whitespace that its native metrics may use.

Saved-response checks verified the changed paths without changing prompts,
budgets, model identities or native scorers. These fixes do not change which
assets a profile requires or certify the entire execution matrix.

Install with `python -m pip install --upgrade agentinputlab==0.1.0a19`.
