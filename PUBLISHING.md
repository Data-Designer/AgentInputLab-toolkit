# Publication policy

Registry publication is manual and requires owner authorization after acceptance. The source tree retains a publication guard for ordinary development builds, and no unattended workflow uploads packages. The npm package remains private; npm publication is deferred.

This toolkit has its own public repository and independent history. Never merge or mirror a private research repository into it, and never change a research repository's visibility to publish toolkit updates. Export only reviewed library changes; keep research data, paper sources, private configuration and credentials outside this repository.

The owner has authorized publication after full toolkit acceptance. Before publication: verify account and namespace ownership, review dependency licenses, run all offline and installed-package tests, scan both distributions, and complete the real-backend acceptance plan across the full catalog. Record unsupported, incomplete and untested combinations accurately; an unimplemented adapter is not a scientifically inapplicable combination. Publication guards remain until acceptance is complete. See [acceptance protocol](docs/toolkit-acceptance.md).
