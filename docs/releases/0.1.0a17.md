# 0.1.0a17: ATD hypothesis-record compatibility

Active Task Disambiguation now accepts complete hypothesis records whose sole
text field is `hypothesis` or `statement`, in addition to `text` and
`description`. Optional display IDs are validated; hypothesis text and ordering
are unchanged. Conflicting fields, duplicate IDs, empty text and
incomplete answer partitions are still rejected.

The fix has been checked with regression tests and continuation from four saved
real responses. Three continuations reached the normal request-for-clarification
boundary; one encountered a later output-budget limit. A clarification request
requires a real user reply and is not reported as a completed benchmark score.

Prompts, hypothesis/question counts, inference settings, budgets and scorers are
unchanged. This release does not claim completion of the ongoing full execution
coverage audit. The existing ToolSandbox tool-call-ID repair remains included.

Install with `python -m pip install --upgrade agentinputlab==0.1.0a17`.
